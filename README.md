# Eliciting System Requirements from Information Breakdowns

Supplementary materials, data, and Python code accompanying:

Kulikovskikh, Behutiye, and Šmuc,
"Eliciting System Requirements from Information Breakdowns: A Pilot Study."

## Contents

- S1 — Miro Board Records
- S2 — Printable Card Templates
- S3 — Supporting Data
- S4 — Python Code

The file `00_board_logs.csv` in S3 contains the original board-log data used as input for the analyses.

The Python code in S4 reproduces the processing, analysis, and figures from the source data.
